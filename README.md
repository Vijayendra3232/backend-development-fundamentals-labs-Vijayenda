## Repository Standards & Rules
- Each lab resides in its dedicated directory (`lab-01/` through `lab-10/`) with its own `README.md`, source code, and `screenshots/` directory.
- `node_modules` and sensitive `.env` files are never committed to version control.
- All HTTP routes explicitly return appropriate status codes (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`, etc.).
- Meaningful commit messages are recorded incrementally for each task.
